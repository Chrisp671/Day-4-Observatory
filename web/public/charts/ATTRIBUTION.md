# Chart data attribution

The files in this directory are generated by `scripts/build-charts.py` from
[d3-celestial](https://github.com/ofrohn/d3-celestial) by Olaf Frohn, commit `7e720a3de062059d4c5400a379146a601d9010e0`,
released under the BSD 3-Clause License (see `LICENSE-d3-celestial.txt`).

d3-celestial's own sources, as its readme records them:

- Star positions and magnitudes: XHIP — An Extended Hipparcos Compilation;
  Anderson E., Francis C. (2012).
- Star names and designations: HD-DM-GC-HR-HIP-Bayer-Flamsteed Cross Index
  (Kostjuk, 2002) and the General Catalogue of Variable Stars (Samus et al.).
- Constellation figures (the connecting lines) and names: the IAU constellation
  page, with d3-celestial's modifications.

Each `<Abbr>.json` holds one constellation: `stars` as `[RA°, Dec°, magnitude,
name-or-empty]` (J2000), and `lines` as polylines of `[RA°, Dec°]`. `index.json`
maps constellation names to abbreviations. Files are loaded on demand by the
Constellations view.
